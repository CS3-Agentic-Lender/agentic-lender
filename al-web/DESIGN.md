# AL-Web Week 3 prototype

- [Clickable Figma prototype](https://www.figma.com/design/F6lldwqy172ox5SeALdDEU/AL-%E2%80%94-Agentic-Lender-Web-Prototype?node-id=3-7)
- [Week 3 design report in Confluence](https://alprojectcs3.atlassian.net/wiki/spaces/AL/pages/7700489/Week+3+report+AI-web+frontend+prototype)

The Figma file covers the Broker and Underwriter journeys from login through their respective loan-file and final screens. It includes role-specific navigation, AI assessment and reasoning, stress testing, decision sign-off, and audit/on-chain result states. The Week 3 deliverable is a clickable mock-up; no React frontend or backend integration is included.

Prototype navigation was checked across 51 demo frames and 678 links. Every link targets an existing frame, and no Broker frame links to an Underwriter-only frame. Search and message composition in the inbox are static prototype controls.
