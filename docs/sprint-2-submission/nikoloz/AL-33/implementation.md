# AL-33: As an underwriter, I open a loan file with the borrower's full DTI breakdown

## What was built

One loan file page per application, for underwriters and for a broker's own clients, opened from the pipeline queue or the client file. It shows the borrower, the loan, the property and the DTI breakdown at the offered and the stressed rate, read only from the stored figures.
