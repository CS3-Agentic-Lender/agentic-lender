# AL-152: As an underwriter, I reply to a borrower's messages as the bank lending officer

## What was built

A "Message borrower" button in the underwriter's loan file opens the borrower's own thread. Messages sent from it are stored with the role underwriter, set by the API, and show as "Bank lending officer".
