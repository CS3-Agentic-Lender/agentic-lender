# AL (Agentic Lender)

MTU Year 3 group project. 

## Structure
- al-mobile/  Android, Kotlin          (Ibrahima)
- al-web/     React, Tailwind          (Nikoloz)
- al-core/    Firebase + Solidity      (Nic + Solomon)
- al-ai/      Python, Flask, ML+agents (Nic + Solomon)
- docs/       sprint docs, use cases, test cases

## Rules
- Never commit secrets. Use .env, update .env.example when adding a key.
- Branch naming: feature/AL-<jira-id>-short-description
- Commit messages start with the Jira ticket id, e.g. "AL-12 add valuation endpoint"
- PRs into main, one approval required.
